📋 Panimula

Ang HOTSPACE VPN ("kami", "app") ay nagpapahalaga sa privacy ng bawat user. Ang Privacy Policy na ito ay nagpapaliwanag kung anong impormasyon ang kinokolekta ng app, paano ito ginagamit, at paano namin pinoprotektahan ang iyong data kapag gamit mo ang aming serbisyo.

Sa paggamit ng HOTSPACE VPN, sumasang-ayon ka sa mga tuntunin na nakasaad sa dokumentong ito.

🔑 Mga Permission na Hinihiling ng App

Para gumana nang maayos ang HOTSPACE VPN, humihiling ito ng mga sumusunod na permission:

  • Internet Access — kinakailangan para makakonekta sa VPN/tunnel server.
  • Network State — ginagamit para ma-detect kung connected ka sa internet (WiFi/Data) bago at habang naka-connect sa VPN.
  • Notifications — ginagamit para ipakita ang status ng koneksyon (connected/disconnected) sa notification bar.
  • Foreground Service / VPN Service — kinakailangan ng Android para tumakbo ang VPN tunnel nang stable sa background.

Hindi humihiling ang app ng access sa contacts, camera, microphone, gallery/photos, o location.

📊 Impormasyong Kinokolekta

Ang HOTSPACE VPN ay isang tunneling/proxy application. Ang mga sumusunod na impormasyon ay maaaring ma-generate lokal sa iyong device habang ginagamit ang app:

  • Configuration settings na iyong ipinasok (halimbawa: server address, port, username/password ng SSH o proxy) — ito ay iniimbak lamang sa loob ng device mo.
  • Connection logs (para lamang sa troubleshooting) na ipinapakita sa app mismo, hindi ipinapadala sa amin.
  • Basic app usage data (hal. crash logs) kung ito ay awtomatikong ipinapadala ng Android system o ng third-party library na ginamit sa app.

Hindi namin kinokolekta ang iyong pangalan, email, o anumang personal na identifying information maliban kung kusang ibinigay mo ito (halimbawa, sa pag-contact sa amin para sa suporta).

🌐 Paggamit ng Data sa Koneksyon

Kapag ginagamit ang VPN/tunnel feature, dumadaan ang iyong internet traffic sa pinili mong server (SSH/SSL/V2Ray, atbp.) na maaaring hostingan ng ikatlong-partido (third-party) provider. Ipinapaalala namin na:

  • Ang app mismo ay hindi nagta-track o nagbebenta ng iyong browsing history.
  • Ang mga third-party server (kung mayroon) na ginagamit ng app ay maaaring may sariling privacy policy na dapat mo ring basahin.
  • Responsibilidad mo bilang user na piliin ang trusted/reliable server kapag mag-a-add ng custom configuration.

🔐 Seguridad ng Data

Ang mga configuration at settings na iyong ipinasok ay naka-store lamang lokal sa iyong device gamit ang standard Android storage mechanisms. Hinihikayat namin ang mga user na huwag mag-share ng kanilang device o app settings sa hindi kilalang tao.

🚫 Hindi Namin Ginagawa

  • Hindi namin ibinebenta ang iyong data sa mga advertiser.
  • Hindi namin ginagamit ang iyong impormasyon para sa unauthorized na third-party marketing.
  • Hindi kami nangongolekta ng sensitive personal data tulad ng financial information sa loob ng app.

👶 Privacy ng mga Bata

Ang HOTSPACE VPN ay hindi dinisenyo para gamitin ng mga bata na wala pang 13 taong gulang. Hindi kami sadyang nangongolekta ng impormasyon mula sa mga bata.
